# 🤖 ORoX — Your First Personal AI Robot Companion

> **ORoX** is an intelligent, emotionally responsive personal desktop AI companion designed with expressive animated face states, interactive 3D physics, real cute robot voice synthesis, and custom personality editions.

---

## ✨ Features

- **Interactive 3D Robot Companion**:
  - Fully real-time Three.js 3D model with dynamic head tilt, physics inertia, and smooth body rotations.
  - Interactive click, drag, and touch-to-rotate controls responsive across desktop and mobile.
- **Expressive Multi-Emotion Face Matrix**:
  - 10+ expressive emotion states: *Happy, Excited, Curious, Blushing, Sleepy, Heart Eyes, Thinking, Winking, Focused, Surprised*.
  - Pixel-perfect OLED face glow with dynamic eye blinking and mood switching.
- **Cute Robot Voice Engine**:
  - Real voice synthesis audio clips with cute anime/chibi sound effects for greetings, emotions, and interactions.
  - Fallback high-pitch Web Audio synthesizer for real-time speech dialogue.
- **Custom Hardware Skins & Special Editions**:
  - Classic Colorways: *Cyber Cyan, Neon Purple, Emerald Green, Solar Gold, Crimson Core, Obsidian Stealth*.
  - Special Editions: *Monkey D. Luffy Straw Hat Edition*, *Iron Armor Mecha*, and *Cute Chibi Figurine*.
- **Suggestion Box & Contact**:
  - Live suggestion box sending directly to `oroxrobot@gmail.com`.
  - Official hotlines: `01763609992` & `01939161125`.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **3D Graphics & Canvas**: Three.js
- **Styling**: Tailwind CSS, Lucide React icons
- **Audio**: Web Audio API + Chibi Cute Voice Synthesis Engine
- **Deployment**: GitHub Pages (Automated via GitHub Actions)

## 🚀 Local Development

1. **Clone the repository**:
   ```bash
   git clone git@github.com:Safin313-stack/ORoX.git
   cd ORoX
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

## 🌐 Deploy to GitHub Pages

This repository includes a pre-configured GitHub Actions workflow in [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

### Enabling GitHub Pages:
1. Push code to the `main` branch.
2. In GitHub, go to **Settings** > **Pages**.
3. Under **Build and deployment** > **Source**, select **GitHub Actions**.
4. The workflow will automatically build and publish your site!
